## Book Rating Site
#### This was a class project that utilizes MongoDB/Mongoose, Express, Redis, and React, and Node.js.
This stack was chosen for me so that I could build a web app that included features such as user accounts, password changes, client data persistence, etc. I chose to make a book rating site. <br>

#### It is currently not hosted - this is something I'm working on! 
I plan to refactor a lot of this project in the future to hopefully launch as a GoodReads alternative. This requires a lot of poliishing and new integrations (like a book api), so this repository is mainly a proof of concept for now.
